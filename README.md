# max_bot

## Распознавание голосовых сообщений

Голосовые сообщения MAX распознаются через Yandex SpeechKit и обрабатываются как обычный текст. Перед отправкой аудио в SpeechKit бот проверяет согласие пользователя.

Задайте `YANDEX_SPEECHKIT_API_KEY` и `YANDEX_FOLDER_ID` в `.env` для локального запуска и в переменных окружения деплоя. API-ключ должен принадлежать сервисному аккаунту с доступом к распознаванию SpeechKit. Без этих переменных распознавание отключено.

Для синхронного распознавания отправляется аудио в формате OGG Opus с языком `ru-RU`.
