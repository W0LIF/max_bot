# Общая база для бота и мини-приложения

Проект поддерживает Turso как постоянное SQLite-совместимое хранилище. Без настройки Turso локально используется файл из `DB_PATH`; Vercel временно переключается на `/tmp/bot.db`, который не сохраняется между cold start.

1. Создайте базу Turso через dashboard, выбрав Turso Database.
2. Скопируйте URL базы и создайте для неё auth token.
3. В Vercel добавьте `TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN` в Production, Preview и Development, затем передеплойте проект.
4. Если `cmd/bot` запускается отдельно, задайте ему те же две переменные окружения. Тогда бот, Vercel API и мини-приложение будут читать и менять одни данные.
5. Добавьте случайный `CRON_SECRET` в Production Vercel для авторизации cron-задачи напоминаний.
6. Оставьте секреты только в настройках окружения. Не коммитьте `.env` или auth token.

В `vercel.json` стоит ежедневный cron, совместимый с Hobby-планом. Hobby не гарантирует точное время и запускает cron с разбросом до 59 минут. Для интервала раз в 15 минут нужен Vercel Pro либо постоянно работающий хост для `cmd/bot`.

Названия всех переменных собраны в [`.env.example`](../.env.example). Для локальной разработки без облачной базы достаточно `DB_PATH=bot.db`.
